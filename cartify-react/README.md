# Cartify – React Ecommerce Frontend

A beginner-friendly frontend shopping demo built using React, React Router, and CSS. Features product browsing, category filters, search, cart quantity controls, cart removal, saved cart using localStorage, and mock checkout.

## Run in VS Code
1. Extract the ZIP file.
2. Open the `cartify-react` folder in VS Code.
3. Install Node.js (LTS) if not installed: https://nodejs.org/
4. Open Terminal in VS Code (Terminal > New Terminal).
5. Run `npm install`
6. Run `npm run dev`
7. Open the local URL printed in terminal (usually http://localhost:5173).

## Notes
Checkout is simulated and does not collect real payments. Product data is sample data and the cart is stored in the browser's localStorage.
